Qwen3-TTS API 文档

基于 mlx-audio 的 OpenAI 兼容语音合成接口，运行于本机 Apple Silicon GPU

模型 Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit 引擎 MLX (Metal GPU) RTF ~0.8x
本地 http://127.0.0.1:18083 | 公网 https://tts.badtom.dpdns.org
OpenAI 兼容 — 接口与 OpenAI Audio API 格式一致，可直接替换 base_url 接入现有应用。模型首次调用时约需 8s 完成加载，之后每次推理约 2~3s。

⚡ 快速开始

curl

bash
curl https://tts.badtom.dpdns.org/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit",
    "input": "你好，欢迎使用语音合成！",
    "voice": "vivian"
  }' \
  --output output.mp3

Python (openai SDK)

python
from openai import OpenAI
from pathlib import Path

client = OpenAI(
    base_url="https://tts.badtom.dpdns.org/v1",
    api_key="not-needed"
)

response = client.audio.speech.create(
    model="mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit",
    voice="vivian",
    input="你好，欢迎使用语音合成！",
)
response.stream_to_file("output.mp3")

Python (requests)

python
import requests

resp = requests.post(
    "https://tts.badtom.dpdns.org/v1/audio/speech",
    json={
        "model": "mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit",
        "input": "你好，欢迎使用语音合成！",
        "voice": "vivian",
        "response_format": "mp3",
    }
)
with open("output.mp3", "wb") as f:
    f.write(resp.content)

instruct 情感/风格指令示例

instruct 字段接受自然语言描述，支持中英文混用，可控制情绪、语速、语调等多维度声学属性。以下为官方验证可用的示例：

instruct 内容效果
用特别愤怒的语气说强烈愤怒情绪
用温柔愉快的语气说话温柔愉悦
Very happy.开心兴奋（英文指令）
Speak slowly and clearly.放慢语速，咬字清晰
用悲伤哽咽的语气悲伤、声音带哽咽感
用轻松随意的聊天语气口语化，自然随意
注：instruct 属于模型层面的自然语言理解，不保证 100% 精确执行，但模型会根据文本语义和指令联合决策最终的表达方式。

示例：情感控制

bash
curl https://tts.badtom.dpdns.org/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{

    "voice": "vivian",
    "instruct": "用特别愤怒的语气说"
  }' --output output.mp3

流式生成（低延迟）

设置 "stream": true 启用流式模式，端到端首包延迟低至 97ms，适合实时对话场景。服务器以 chunked transfer 返回音频流。

python
import requests

with requests.post(
    "https://tts.badtom.dpdns.org/v1/audio/speech",
    json={
        "model": "mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit",
        "input": "你好，这是一段流式合成的语音。",
        "voice": "vivian",
        "stream": True,
        "streaming_interval": 2.0,  # 每 2 秒推送一个音频块
    },
    stream=True,
) as r:
    with open("output.mp3", "wb") as f:
        for chunk in r.iter_content(chunk_size=4096):
            f.write(chunk)

语音合成（TTS）

POST /v1/audio/speech 文本转语音

将输入文本合成为音频文件，直接返回二进制音频流（mp3/wav/flac）。

⚠️ 与标准 OpenAI API 的关键差异 — 接入第三方应用必读
本接口格式兼容 OpenAI，但 voice 字段不兼容 OpenAI 的音色名称（alloy、nova、echo 等）。voice 为必填字段，且必须是音色列表中的 9 个名称之一。

已验证的错误行为：
  • 不传 voice：服务器内部异常，返回 520 错误
  • 传 OpenAI 默认音色（如 alloy）：返回 HTTP 200，但音频为无法识别的乱码
两种情况均不返回有意义的错误信息，排查困难。第三方应用接入时务必显式覆盖默认音色。

请求体参数（application/json）

参数类型默认值说明
modelstring—必填 模型 ID，如 mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit
inputstring—必填 要合成的文本内容
voicestringnull必填 预设音色名，见 音色列表，如 vivian、ryan、uncle_fu
response_formatstringmp3可选 输出格式：mp3 / wav / flac
instructstringnull可选 情绪/风格指令，如 用温柔愉快的语气说话、Very excited.
lang_codestringauto可选 语言代码，见语言列表，如 chinese、english
speedfloat1.0可选 语速倍率
pitchfloat1.0可选 音调
ref_audiostringnull可选 声音克隆参考音频路径（服务器本地路径）
ref_textstringnull可选 参考音频对应文本
temperaturefloat0.7可选 采样温度，越高越随机
top_pfloat0.95可选 核采样概率
top_kint40可选 Top-K 采样
max_tokensint1200可选 最大生成 token 数
streamboolfalse可选 流式返回，首包延迟低至 97ms，适合实时对话
streaming_intervalfloat2.0可选 流式模式下每个音频块的时长（秒）

示例：基础合成

bash
curl https://tts.badtom.dpdns.org/v1/audio/speech \
  -H "Content-Type: application/json" \
  -d '{
    "model": "mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit",
    "input": "大家好，今天我们来聊聊人工智能的发展。",
    "voice": "vivian",
    "response_format": "mp3"
  }' --output speech.mp3

示例：指定音色 + 调整语速与音调

示例：声音克隆（服务器本地参考音频）

bash
curl https://tts.badtom.dpdns.org/v1/audio/speech \

第三方应用接入（OpenAI 兼容客户端）

⚠️ 必须显式设置 voice — 大多数 OpenAI 兼容客户端会自动填充默认音色（通常是 alloy），这在本服务中会生成乱码音频。接入时请务必覆盖默认值。

以 OpenAI Python SDK 为例，需在调用时传入支持的音色名：

python
from openai import OpenAI

client = OpenAI(
    base_url="https://tts.badtom.dpdns.org/v1",
    api_key="not-needed",
)

# ✅ 正确：显式指定支持的音色名
response = client.audio.speech.create(
    model="mlx-community/Qwen3-TTS-12Hz-1.7B-CustomVoice-8bit",
    voice="vivian",  # 必须是 9 个支持音色之一
    input="你好，欢迎使用！",
)
response.stream_to_file("output.mp3")

# ❌ 错误：使用 OpenAI 默认音色（alloy/nova/echo 等）会返回乱码音频
# response = client.audio.speech.create(..., voice="alloy", ...)

语音识别（STT）

POST /v1/audio/transcriptions 音频转文字

将音频文件转录为文本，兼容 OpenAI Whisper API 格式。需搭配 STT 模型使用（非当前 TTS 模型）。

参数类型默认值说明
filefile—必填 音频文件（multipart/form-data）
modelstring—必填 STT 模型 ID
languagestringnull可选 语言代码，如 zh、en
streamboolfalse可选 流式返回

音频分离

POST /v1/audio/separations 音轨分离（人声/乐器等）

基于 SAM Audio 模型分离指定音轨，如提取人声、鼓点、吉他等。

参数类型默认值说明
filefile—必填 音频文件
modelstringmlx-community/sam-audio-large-fp16可选 分离模型
descriptionstringspeech可选 要分离的内容，如 speech、guitar
stepsint16可选 ODE 步数：2/4/8/16/32

响应

json
{
  "target_audio": "<base64编码的目标音轨>",
  "residual_audio": "<base64编码的剩余音轨>",
  "sample_rate": 44100
}
